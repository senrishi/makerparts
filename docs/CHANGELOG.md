# Changelog

## 0.1.8

- Redesigned Cloud sync settings around automatic sync and a single Sync now action.
- Combined independent edits automatically and queued sync when local changes are saved.

## 0.1.6

- Added optional cloud sign-in and automatic project library sync.
- Added sync status, manual refresh, and explicit choices when hosted and local copies diverge.

## 0.1.5

- Added a Mozilla-signed, unlisted Firefox package for self-distribution.
- Retained the public AMO listing as a separate release channel.

## 0.1.4

- Added project text copying with or without product links.
- Grouped copied parts beneath underlined category headings and omitted purchase status.
- Fixed an extra character in the project toolbar.

## 0.1.3

- New part and cart saves remember the project used for the most recently added part.
- Added the remembered destination to local backups.

## 0.1.2

- Added Restore Project for validated Planned parts and Clear Cart for MakerBazar.
- Added a local previous-cart recovery copy for restore operations.

# MakerParts

**Keep electronics parts organized by project, with product links, exact variants, and cost estimates in one place.**

MakerParts is a local-first browser extension for collecting components while you plan a build. Save parts from product pages into separate project lists instead of letting unrelated builds accumulate in one store cart.

## Features

- Save a product from any site with the toolbar button; review and edit the captured name, model, link, category, quantity, and price.
- Use the MakerBazar floating button for quick capture, cart saving, cart clearing, and restoring a project’s planned parts.
- Organize parts into projects or the built-in **Miscellaneous** list. Categories include microcontrollers and boards, active and passive components, resistors, capacitors, sensors, and more.
- Track parts as planned, ordered, or received. Project totals show estimated parts value by currency.
- Copy a project as readable text grouped under category headings, with or without product links.
- Choose a matte dark, light, or system theme. Export and import JSON backups when moving between profiles.

## Browser support

MakerParts supports Chrome’s Manifest V3 and signed Firefox releases targeting Firefox 140 and newer. Firefox requires a Mozilla-signed package for a permanent installation. See [installation](docs/INSTALL.md) for the available packages and steps.

## Privacy

Your library is stored in the current browser profile. MakerParts does not require an account and does not send parts, prices, or carts to a MakerParts server. Site access outside MakerBazar is limited to a page when you click the toolbar button. Read the [privacy and permissions summary](docs/PRIVACY.md).
